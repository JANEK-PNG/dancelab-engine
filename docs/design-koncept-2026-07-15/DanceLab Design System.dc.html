2a — LIQUID GLASS
Liquid Glass, applied to a dark pro-audio tool
Grounded in SwiftUI's real .glassEffect() API and its HIG rules, not a generic frosted-panel guess.
Core Rules Applied Below
1. Regular vs Clear — never mixed in one control group.
2. Glass is a navigation layer only — never applied to content itself.
3. Glass can't sample glass — nearby glass elements share one container.
4. Interactive (scale/bounce/shimmer) only on tappable controls.
5. Tint only for semantic meaning — primary action or state, never decoration.
6. Shapes stay concentric — capsule default, corners nest with their container.
Glass Material Tokens
Regular
bg rgba(20,26,36,.5) · blur(26px) · border rgba(255,255,255,.16)
Adaptive — tints toward content behind it. Used for sidebars, toolbars, controls.
Clear
bg rgba(10,14,20,.24) · blur(34px) · scrim required
Permanently transparent. Needs a dark dimming scrim under text — never used bare for legibility.
Tinted Regular
Regular glass tinted with accent-primary — marks the active/selected control without breaking material rules.
Glass Components
Shared GlassEffectContainer — one sampling region

Needs Review
In SwiftUI these five controls would sit inside one GlassEffectContainer(spacing:) so they morph and light-react as a unit instead of sampling independently. CSS backdrop-filter has no shared-sampling equivalent, so the dashed boundary marks where that grouping belongs.
