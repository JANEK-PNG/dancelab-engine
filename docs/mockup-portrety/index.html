Trzy portrety brzmienia — jeden artysta, te same dane

Każdy portret rysowany WYŁĄCZNIE z prawdziwych szwów tego DJ-a w mapie (sekwencje przejść: tempo A → tempo B, skok, zgodność harmoniczna, kolejność w secie). Zero losowości poza deterministycznym ziarnem — ta sama osoba zawsze dostaje ten sam portret.

I · Pierścień przejść

Geometria sakralna z rzemiosła: obwód to oś temp (95–190). Każdy szew to cięciwa od tempa wyjścia do tempa wejścia. Kolor mówi o harmonii, grubość o skoku. DJ „wąski" rysuje ciasny wachlarz, DJ-skoczek — pajęczynę.
cięciwy:zgodne harmonicznie sąsiednie/równoległe bez zgodności · grubość = skok tempa

II · Sejsmograf

Brutalizm pomiaru: papier milimetrowy, jeden wiersz na set, igła skacze o realny skok tempa przy każdym szwie. Zgodny harmonicznie szew to cienka kreska, zgrzyt — gruby czarny słupek. Zero koloru, sama prawda zapisu.
oś pozioma = kolejne szwy w secie · wychylenie = ±skok BPM · słupek = szew bez zgodności harmonicznej

III · Ogród

Organika: każdy set wyrasta z ziemi jako łodyga — wysokość to liczba szwów. Liście wyrastają pod kątem skoku tempa (spokojny DJ = łagodna paproć, skoczek = jeżozwierz), kwiat na szczycie ma kolor mediany tempa setu.
łodyga = set · liść = szew (kąt = skok, kolor = harmonia) · kwiat = mediana tempa setu (chłodny→ciepły)
