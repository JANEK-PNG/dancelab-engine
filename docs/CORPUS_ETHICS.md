# DanceLab Corpus Fair-Play Policy

Jan's commitment, 2026-07-16: *"I love this industry, so I want to be as fair as
I possibly can."* This is project policy, not a PR statement.

1. **Features, then delete.** Once alignment is finished, the corpus's raw audio
   is deleted. What remains is beat-synchronous features (chroma / MFCC — not
   invertible back to music), the alignments, and statistics. This satisfies the
   retention condition of the Polish TDM exception (act of 26 July 2024).
2. **Zero redistribution.** Corpus audio never leaves the working drive, never
   plays inside the application, and is never published.
3. **Art uses metadata only.** The transition portraits (PRZEJŚCIA) and the
   Inspiration Board use facts about transitions — who, what, after what, for how
   long — plus links to legal sources of the sets. Always with an evidence count.
4. **The digging list is a shopping list.** Tracks discovered through the corpus
   get bought: money flows to the artists we analyse.
5. **Attribution.** Every analysis result points back to its source set (mixesdb
   or SoundCloud URL). The alignment method is DLASOT-13 (Kim et al., ISMIR 2020)
   and is cited as such.
6. **Opt-out is honoured retroactively.** If an artist or label asks for their
   data to be removed from the corpus, it is removed without argument.
7. **Before any exhibition or commercial use: IP counsel.** Internal analysis is
   not a legal opinion.
