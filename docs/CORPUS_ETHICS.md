# Zasady fair play korpusu DanceLab

Zobowiązanie Janka, 2026-07-16: "kocham tę branżę, więc chcę być fair tak,
jak to tylko możliwe". To jest polityka projektu, nie deklaracja PR.

1. **Features-then-delete.** Po zakończeniu alignmentu surowe audio korpusu
   jest kasowane. Zostają wyłącznie: cechy beat-sync (chroma/MFCC — nieodwra-
   calne do muzyki), alignmenty, statystyki. Zgodne z warunkiem retencji
   polskiego wyjątku TDM (ustawa z 26.07.2024).
2. **Zero redystrybucji.** Audio korpusu nigdy nie opuszcza dysku roboczego,
   nigdy nie gra w aplikacji, nigdy publicznie.
3. **Sztuka = metadane.** Portrety (PRZEJŚCIA) i Inspiration Board używają
   wyłącznie faktów o przejściach (kto/co/po czym/jak długo) + linków do
   legalnych źródeł setów. Zawsze z licznikiem dowodów.
4. **Digging list = zakupy.** Tracki odkryte przez korpus kupujemy —
   pieniądze płyną do artystów, których analizujemy.
5. **Atrybucja.** Każdy wynik analizy wskazuje set źródłowy (mixesdb/
   SoundCloud URL). Metoda: DLASOT-13 (Kim et al., ISMIR 2020) — cytowana.
6. **Opt-out respektowany wstecz.** Jeśli artysta/wytwórnia zażąda usunięcia
   swoich danych z korpusu — usuwamy bez dyskusji.
7. **Przed wystawą/komercją: prawnik IP.** Analiza wewnętrzna ≠ opinia prawna.
