# PRZEJŚCIA — portrety DJ-ów z danych (projekt-satelita, sztuka)

Status: koncept zatwierdzony przez Janka 2026-07-16 ("Przejścia brzmi
genialnie"). Satelita korpusu — żywi się alignmentami, nie konkuruje
z kolejką walidacji. Pierwszy krok: prototyp portretu Bena UFO po
zakończeniu pełnej analizy korpusu.

## Idea

Portret DJ-a wygenerowany wyłącznie z jego zmierzonych przejść (DTW
alignment realnych setów). Człowiek sportretowany momentami, w których
łączy dwie rzeczy. Zero dekoracji: każdy element wizualny = zmierzony
wymiar zachowania.

## Gramatyka wizualna (v0)

- pierścień zewnętrzny: rozkład temp (tarcza BPM)
- grubość łuków: długości przejść (blend vs cięcie)
- znaczniki koła 32 beatów: pozycje cue względem frazy
- przesunięcia barwy: ruch harmoniczny (Camelot = koło barw)
- sylwetka środka: krzywa energii typowego setu
- ziarno tekstury: match confidence — niepewność pomiaru widoczna
- PUSTKA = treść: niezmatchowany materiał zostaje pusty (portret
  Jamiego xx ≈ negatyw — gra to, czego świat nie ma; Ben UFO ≈ pełny).
  Uczciwość pomiaru jako język formalny.

## Formaty ekspozycyjne

1. Tryptyki czasu: ten sam DJ 2010/2015/2019 (daty setów w datasecie)
2. B2B jako dwugłos: Ben UFO b2b Helena Hauff (mix3083)
3. Interaktyw: widz wybiera 2 DJ-ów → morf przez "most" wspólnych tracków
4. Druk generatywny/ploter, numerowany
5. Tytuł: **PRZEJŚCIA**

## Nota prawna

Portret z metadanych + nazwisko w kontekście artystycznym = wypowiedź
artystyczna (bezpieczne). Merch/komercja → osobna analiza. Audio w galerii
→ licencje; sam obraz czysty. Audio korpusu nigdy nie gra publicznie.
